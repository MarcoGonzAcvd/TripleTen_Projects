# 🛒 Limpieza y Procesamiento de Datos de Clientes — Store 1

## 📌 Descripción del Proyecto
La empresa de comercio electrónico **Store 1** planea lanzar un nuevo *Programa de Fidelización de Clientes*. Para garantizar el éxito de las futuras campañas de marketing y la segmentación de usuarios, este proyecto realiza la limpieza, estandarización y transformación inicial de la base de datos de clientes.

El análisis transforma un conjunto de datos en listas nativas de Python en una estructura consistente, validada y lista para la generación de KPIs de negocio.

---

## 🛠️ Objetivos Principales
- **Limpieza de Perfiles:** Identificar y corregir inconsistencias o errores en los registros de usuario.
- **Estandarización:** Normalizar formatos de nombres y edades.
- **Transformación de Datos:** Calcular el gasto total por cliente a partir de sus compras por categoría.
- **Preparación de KPIs:** Dejar los datos optimizados para análisis de segmentación por edad, historial de compras y categorías preferidas.

---

## 📊 Estructura de Datos
Los datos originales procesados contienen los siguientes campos:
- `usuario_id`: Identificador único del usuario.
- `usuario_nombre`: Nombre del usuario.
- `usuario_edad`: Edad del usuario.
- `categorias_fav_low`: Categorías de productos con mayor frecuencia de compra (Electrónica, Deporte, Libros, etc.).
- `gasto_por_categoria`: Desglose del monto gastado por categoría.

---

## 🔧 Herramientas Utilizadas
- **Lenguaje:** Python (Estructuras de datos, bucles, manejo de listas).
